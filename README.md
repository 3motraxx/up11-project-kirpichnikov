Мир Одежды — система оформления и учета заказов одежды

Настольное приложение торговой компании «Мир одежды»: удобный каталог одежды, оформление заказов клиентами, а также полное управление складом и заказами для менеджера и администратора.

Используемые технологии

- Язык программирования: Python 3.10+
- Платформа (фреймворк) интерфейса: PyQt / PySide
- СУБД: PostgreSQL, драйвер psycopg2

Назначение и основные функции

Каталог товаров
-- Загрузка каталога: отображение данных из базы данных — изображение, категория, подкатегория, наименование, производство, состав, описание, базовая цена и общее количество на складе.
-- Индикация остатков: подсветка товаров, у которых суммарный остаток на складе составляет 3 единицы и меньше.
-- Заглушка изображений: если картинка товара отсутствует или недоступна, автоматически подставляется 'picture.png'
-- Интерактивный поиск и фильтры: мгновенный поиск по наименованию, фильтрация по категориям, а также сортировка цен (в реальном времени).

Авторизация и роли
-- Вход в систему: авторизация по логину из базы данных (без пароля). ФИО вошедшего пользователя отображается в интерфейсе.
-- Гость: просмотр каталога товаров без возможности оформлять заказы.
-- Авторизованный пользователь: просмотр каталога с поиском и фильтрами, добавление товаров в корзину и оформление заказов.
-- Менеджер: всё, что доступно пользователю, плюс просмотр списка всех заказов, их состава, добавление и удаление заказов.
-- Администратор: полный доступ ко всем функциям менеджера, а также редактирование заказов (изменение дат и удаление позиций).

Оформление заказа и работа со складом
-- Корзина: добавление позиций, выбор количества с обязательной проверкой (количество не должно превышать текущий остаток на складе).
-- Транзакционное обновление: при подтверждении заказа в одной транзакции создается запись в базе данных, а складские остатки ('stock_items') автоматически уменьшаются на купленное количество.
-- Возврат при удалении: при удалении заказа товарные позиции автоматически возвращаются обратно на склад.

│ ├── connection.py — управление соединениями и транзакциями
│ ├── order_repository.py — запросы и логика работы с заказами
│ ├── product_repository.py— запросы к каталогу товаров
│ └── user_repository.py — работа с пользователями
├── ui/ — графические интерфейсы и окна приложения
├── resources/ — папка ресурсов (logo.png, icon.ico, picture.png)
└── requirements.txt — зависимости проекта
